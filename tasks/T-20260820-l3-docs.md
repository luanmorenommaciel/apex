# Document readability across the lane docs

> **Why:** VALIDATION records what was observed, so leaving it at five tools makes it a false record rather than a stale one.

## Goal

Reflect the detail levels, explain_stage, coverage and tail share in every lane document.

## Context

Do not touch docs/lanes/SERVE.md here - that write surface belongs to its own unit, as L2 learned when an eval reached outside its blast radius.

## Behavior

- **B-1** — GIVEN serve/README.md WHEN read THEN the tool table lists explain_stage and the detail levels are documented
- **B-2** — GIVEN serve/VALIDATION.md WHEN read THEN it records a test count copied from an actual run
- **B-3** — GIVEN docs/lanes/SERVE-LEGS.md WHEN read THEN L3 marks F3.1 to F3.4 delivered

## Success Criteria

```bash
# eval_1: no owned document still claims a five-tool surface
eval_1() {
  ( ! grep -rniE 'five tools|exactly 5 tools' serve/README.md serve/VALIDATION.md docs/lanes/SERVE-LEGS.md )
}

# eval_2: the recorded test count equals what the suite reports
eval_2() {
  ( cd serve && n=$(uv run --extra dev pytest 2>&1 | grep -oE '[0-9]+ passed' | grep -oE '[0-9]+') && grep -q "$n passed" VALIDATION.md )
}

```
