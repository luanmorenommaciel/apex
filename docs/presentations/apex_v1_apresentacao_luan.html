05 / 08
Vantagens competitivas confirmadas

Onde ganhamos — 3 vitórias claras

01
Raciocínio profundo
Root cause com nome do stage, ratio, recomendação específica com config. DataFlint para em "Partition Skew detected."
Apex: "Stage 5 · 180s · 8.8KB shuffle · 1 task → investigar GC + AQE"
DataFlint: "⚠ Partition Skew detected."
02
Zero JAR
Funciona em qualquer Spark sem modificar o cluster, classpath ou SparkSession. DataFlint exige JAR no classpath de cada job.
Apex: lê event log após o job → zero intrusão
DataFlint: --jars dataflint-sdk.jar → bloqueado em clusters gerenciados
03
MCP nativo
Engenheiro pergunta ao Claude Code ou Cursor sobre o job e recebe diagnóstico + fix. DataFlint não tem interface de agente.
Eng: "oi Claude Code, o que tá lento no job?"
MCP: get_findings → root_cause + recomendação → resposta in-IDE
