Fluxograma de decisão · T1 → T2 → T3 · quando acionar cada tier

Lógica de diagnóstico — como decidir

T1 — Determinístico
SQL direto no ClickHouse. Zero LLM, zero rede. 136ms. Detecta skew por records e por duration. Cobre: skew, spill, parallelism.
EvidenceValidator — Gate de qualidade
8 regras antes de qualquer ação. Previne falsos positivos. 198ms. Descarta se evidência insuficiente.
T2 — Runbook JSON
Quando confidence > 0.7. 0.01ms. JSON versionado com 4 steps + código PySpark. Auditável, on-premise, sem API externa.
T3 — Crew.ai (fallback)
Quando confidence < 0.7. ~30s. 2 agentes LLM: MetricsAnalyzer → RecommendationWriter. Fix com código de exemplo.
Resultado
apply_fix() no IDE fecha o loop: MCP lê o finding, LLM edita o .py, backup automático salvo.
