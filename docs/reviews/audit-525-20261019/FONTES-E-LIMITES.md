# Fontes e limites da edição pública

Esta edição disponibiliza as **525 fichas documentais completas (14 campos)**, inventário navegável e 158 registros canônicos. A revisão original tem cortes por ficha; o adendo de 19/10 atualiza somente os objetos nele identificados. Fontes primárias públicas são issues, PRs, diffs, commits e runs citados; fontes locais e relatos têm limite explícito.

Não foram publicados dumps integrais, logs, pastas pessoais, custódia privada ou saídas completas das outras ferramentas. Os nomes de recibos no campo Fontes identificam os registros de origem, mas não são links públicos. CATALOGO-RECIBOS.json registra os nomes e hashes locais quando disponíveis; hash não comprova execução, autorização ou disponibilidade externa. Isso permite comparar o acervo preservado, não reproduzir integralmente a coleta sem esse acervo.

Caminhos absolutos pessoais foram substituídos por `[caminho local omitido]`. Conteúdo técnico, autores, IDs, SHAs, estados, limites e critérios das fichas foram preservados. As expressões “local”, “minuta” e “não publicado” em fichas históricas continuam relativas à sua fonte/corte. Publicar esta edição não altera retroativamente esses fatos.

Os 158 registros contêm um campo historical_record, preservado para genealogia, e correções posteriores em codex_note. O estado histórico não prevalece sobre o adendo atual. Integração, aceites, CI útil e runtime são dimensões separadas; 525/525 é fechamento documental, não entrega de todo o backlog. Responsáveis, prioridades e prazos continuam propostas quando não houver registro humano.

Esta edição pública não é backup integral do workspace e não autoriza apagar o acervo local. Não foram executados produto, testes, serviços ou workflows manualmente para publicá-la. Workflows automáticos disparados pelo GitHub mantêm os próprios recibos.
