Evidence Validator — 7 Regras

Regras estruturais

  • schema_version obrigatório
  • evidence_id único
  • timestamp ISO8601 válido
  • workload_id presente

Regras semânticas

  • severity ∈ {INFO, WARNING, CRITICAL}
  • confidence ∈ [0,1]
  • recommendation não vazia

Baseline — DataFlint

✅ O que faz bem

  • SaaS pronto — sem setup de infra
  • 14 alertas pré-configurados

❌ O que falha

  • JAR obrigatório no cluster Spark
  • Alerta binário (sem nuance)
  • Sem pipeline estruturado
  • Sem integração IDE
  • Modelo pago
Apex faz melhor: Zero JAR, pipeline em 4 tiers, MCP nativo, extensível via YAML, gratuito/open-source
