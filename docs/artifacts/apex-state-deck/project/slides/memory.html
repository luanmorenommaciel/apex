Dois níveis de busca

exact: mesmo plan_fingerprint. structural: cosseno sobre um vetor determinístico de mais de 199 dimensões, sem modelo e sem custo.

Quatro portões

Atribuibilidade (2 ou mais configs), suporte de grupo (mediana, nunca o mínimo), comparabilidade de input e piso de ruído medido.

Piso de ruído real

Mediana de 15,9% e p90 de 76,4% em 65 células de runs idênticas. Cada formato usa a própria variância.

Limite medido

Seis fingerprints distintos codificam para cosseno 1,0000: a redação apagou a diferença. Por isso o tier exact existe.
