1 · Contexto e objetivo

O Commander Luan Moreno enviou a lição de casa ao grupo: "Como desacoplar o gerador de código do gerador de plano? Conseguimos fazer isso?" A resposta era construir um sistema onde dois geradores independentes leem o mesmo contrato YAML e produzem cada um o seu artefato — sem que nenhum execute Spark e sem que nenhum chame o outro.

O objetivo central: provar que é possível gerar um event log sintético fiel ao Spark real sem rodar Spark, tornando os testes do Watcher rápidos (milissegundos) e rodáveis a cada Pull Request.

Premissa inegociável
Não-intrusivo: zero JAR no cluster, zero modificação da SparkSession, zero listener de terceiros. A coleta usa apenas o event log nativo do Spark, lido out-of-process a partir do object storage (MinIO/S3).

3 · Jornada v1 → v3

v1 — o pacote original (05 jun 2026)

O time entregou um pacote com scenario.yaml, code_generator.py, plan_generator.py e evidências do run real. O desacoplamento estrutural estava correto. Três defeitos foram encontrados rodando o código:

Defeito 1 — linha fictícia
Contrato declarava anti_pattern_line: 58, mas o código gerado colocava o join na linha 29 (arquivo de 34 linhas). A correlação código↔telemetria nascia quebrada.
Defeito 2 — campos inventados
Log sintético usava taskMetrics.shuffleReadMetrics.recordsRead. O campo real do Spark é Task Metrics → Shuffle Read Metrics → Total Records Read (JsonProtocol, capitalizado). Um Watcher feito contra o sintético não leria log real.
Defeito 3 — 1 task, sem distribuição
Skew é a cauda (task quente vs mediana das frias). Com 1 task, nenhum detector consegue computar a distribuição.

v2 — correções + run real

Corrigi os três defeitos e rodei o job no cluster real do plat-v0:

# submeter ao cluster real
docker cp job_v2.py spv0-spark-master:/opt/spark/
docker exec spv0-spark-master /opt/spark/bin/spark-submit \
  --master spark://spv0-spark-master:7077 \
  --conf spark.eventLog.compress=false \
  /opt/spark/job_v2.py
# app ID: app-20260606030054-0000
# ResultStage 2: 8 tasks — task 0: 6973ms (hot), demais: 384-980ms

O event log foi baixado do MinIO, descomprimido com zstd -d, e o Watcher detectou GATE VERDE no log real.
